# Pinned, hash-verified dependency set for the de-identification NER pass
# (Presidio + spaCy), used ONLY by the one-off corpus-export ECS task.
#
# WHY THIS FILE EXISTS
# --------------------
# export-corpus.yml used to run, inside the production task definition:
#
#     pip install presidio-analyzer presidio-anonymizer && python -m spacy download en_core_web_lg
#
# with no version pins, no hashes and no index restriction — in a container
# holding DATABASE_URL and the app task role, with assignPublicIp=ENABLED, and
# with `ner` defaulting to "true" so it was the NORMAL path. A compromised or
# typosquatted release of either package, of ANY transitive dependency, or of the
# spaCy model endpoint would have executed arbitrary code against the full PHI
# database and the app's S3/Bedrock/KMS permissions before the export even
# started. It also bypassed the ECR scan_on_push control, which only ever
# inspected the baked image.
#
# `pip install --require-hashes` makes the install reproducible and tamper-evident:
# every artifact, including the whole transitive closure, must match a hash
# recorded here. A substituted or backdoored wheel fails the install instead of
# running.
#
# NOT in pyproject.toml on purpose: these are not app dependencies. The API image
# must not carry a 382 MB NLP model, and nothing in the request path imports them
# (deidentify.py loads Presidio lazily and degrades cleanly when it is absent).
#
# HOW TO REGENERATE
# -----------------
# Resolved for the CONTAINER's platform (linux/amd64, CPython 3.11), not a laptop:
#
#     pip download --platform manylinux2014_x86_64 --python-version 3.11 \
#         --implementation cp --only-binary=:all: --dest wheels \
#         "presidio-analyzer==<v>" "presidio-anonymizer==<v>"
#     for w in wheels/*.whl; do
#       python - "$w" <<'PY'
#     import hashlib, sys, pathlib
#     p = pathlib.Path(sys.argv[1]); n, v = p.name.split("-")[:2]
#     print(f"{n.replace('_','-').lower()}=={v} \\\n    --hash=sha256:{hashlib.sha256(p.read_bytes()).hexdigest()}")
#     PY
#     done
#
# FOLLOW-UP (not done here): bake this set into a second image stage pushed to
# ECR so it is scanned, and give the export its own task definition. That removes
# runtime installation from a PHI task entirely, rather than making it verifiable.
#
# The spaCy model is pinned by URL + hash at the bottom of this file.
